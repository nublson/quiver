title: login
description: Authenticate with GitHub via device flow.
---

<CmdRef signature="quiver login [--force]" since="0.1.0">
Starts the GitHub device flow and stores the resulting token in your OS keychain. Idempotent — running it again on an authenticated machine is a no-op unless you pass `--force`.

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--force` | boolean | false | Re-authenticate even if a valid token exists. |
| `--scope` | string | gist,read:user | Override requested scopes. Advanced only. |
</CmdRef>
