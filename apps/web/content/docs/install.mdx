Quiver is distributed via npm and requires Node.js 18 or newer.

<Terminal label="npm · global" copy="npm install -g usequiver">
  <span className="c-prompt">$</span> <span className="c-cmd">npm install -g</span> <span className="c-str">usequiver</span>
</Terminal>

Verify the install:

<Terminal label="verify" copy="quiver --version">
  <span className="c-prompt">$</span> <span className="c-cmd">quiver</span> <span className="c-flag">--version</span>{"\n"}
  <span className="c-mute">quiver/0.2.4 darwin-arm64 node-v20.11.1</span>
</Terminal>

Prefer not to install globally? You can also run it with `npx`: `npx usequiver sync`. The CLI behaves identically; only the invocation differs.
