---

Then, on every other machine you log into:

<Terminal label="on the new machine" copy="quiver login&#10;quiver sync">
  <span className="c-prompt">$</span>{" "}<span className="c-cmd">quiver</span>{" "}<span className="c-flag">login</span>{"\n"}
  <span className="c-ok">✓ authenticated as nublson</span>{"\n"}
  {"\n"}

  <span className="c-mute">remote rev #23 · 7 skills · local rev #19 · 4 skills</span>{"\n"}
  <span className="c-ok">+ frontend-design</span>{"\n"}
  <span className="c-ok">+ pdf-reading</span>{"\n"}
  <span className="c-ok">+ react-best-practices</span>{"\n"}
  <span className="c-ok">✓ synced 3 new skills · 4 already present</span>
</Terminal>

That's the whole loop. Run `quiver push` when you add new skills, `quiver sync` on machines that need to catch up.
